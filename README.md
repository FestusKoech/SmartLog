-- Objectives --
Functional Objectives of the System

The system allows authorized staff to register new students and laptops efficiently.

The system restricts access based on user roles—staff can handle student and laptop registration.

The system enables administrators to view, search, and export detailed activity reports for accountability and auditing purposes.

The system allows quick lookup of student or laptop details using keywords, using search functionality.

The system provides visual logs and exportable CSV reports that summarize laptop movements.

-- Non-Functional Objectives of the System --

To ensure data security and user authentication
The system enforces secure login and role-based permissions to prevent unauthorized access, ensuring that sensitive student and laptop information remains protected at all times.

To provide a user-friendly and responsive interface
The web interface is designed with simplicity and accessibility in mind, using a clean Bootstrap layout that adapts seamlessly to desktops, tablets, and mobile devices for ease of use by all users.

To guarantee system reliability and data consistency
All database transactions—such as laptop registration, student updates, and QR scans—are handled with integrity checks to prevent duplication or data loss, ensuring consistent and accurate records.

To maintain scalability for future institutional growth
The system architecture supports future expansion to accommodate more users, devices, and multiple access points (such as different campus gates) without compromising performance.

To ensure high system performance and responsiveness
The backend queries and operations are optimized to provide real-time results, fast searches, and quick response times even as data volume increases.

To support maintainability and system updates
The system’s modular code structure and use of standard frameworks (Flask, Bootstrap, and MySQL) make it easy to maintain, debug, and extend with new features as institutional needs evolve.
